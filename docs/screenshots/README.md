# Screenshots

These images are referenced by the repo's root `README.md`, which is also what the
[Obsidian community plugin page](https://community.obsidian.md/plugins/momentum-life)
renders — Obsidian pulls `manifest.json` and `README.md` straight from this repo, so
updating the gallery here updates the directory listing too.

Because the community page renders the README outside of GitHub's relative-path context,
the gallery references these files by **absolute `raw.githubusercontent.com` URL**. Keep the
filenames below exactly as-is so those URLs keep resolving, and keep the paths free of
spaces (a space becomes `%20` and is easy to get wrong).

One screenshot per tab:

and avoid real personal data (amounts, names) in anything published.
